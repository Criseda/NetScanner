# Curated port names, merged over the IANA registry by generate_ports.py.
#
#   port | label | category | iana | description
#
# label        Short display name (max 20 characters). Blank keeps the
#              IANA service name. Required for ports IANA does not assign.
# category     One of: web remote file mail dns database directory media
#              printing messaging voip network vpn proxy home (or blank).
# iana         Which IANA name to report when IANA lists several for the
#              port and the first is not the one in use. Usually blank.
# description  Replaces the IANA description. Blank keeps IANA's.
#
# Only add ports people actually meet on a LAN. When a port is commonly
# used for something other than its IANA assignment, say so in the
# description; the IANA name is still reported next to it. After editing,
# run `python scripts/generate_ports.py` and commit both files.
